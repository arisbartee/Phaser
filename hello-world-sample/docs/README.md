# Fancy Hello World

This project is a single-file, self-contained HTML "Hello World" application demonstrating a modern, interactive web design using vanilla HTML, CSS, and JavaScript.

## Features

- **Modern Aesthetics**: Utilizes a dark mode theme with a radial gradient ambient background, creating a sleek visual foundation.
- **Glassmorphism**: Features a central container styled with semi-transparent backgrounds and `backdrop-filter` for a frosted glass effect.
- **Dynamic CSS Animations**: Includes continuous animations such as a subtle floating effect on the container, a background gradient pulse on the main text, and an ambient glowing orb in the background.
- **Interactive JavaScript Particle Burst**: Clicking anywhere on the screen triggers a vibrant, physics-based particle burst effect rendered via a full-screen HTML5 `<canvas>`.
- **Tactile Feedback**: The main heading subtly scales down and back up on click to provide immediate visual feedback.
- **Fully Responsive**: Adapts perfectly to tablet and mobile screen sizes using CSS media queries.
- **SEO Optimized**: Includes essential meta tags and Open Graph data for optimal discoverability.

## How to Run

Simply open `index.html` in any modern web browser. No local server or build tools are required since all assets (HTML, CSS, JS) are contained within the single file.

## Technologies Used
- HTML5
- CSS3 (Variables, Keyframes, Media Queries, Glassmorphism)
- Vanilla JavaScript (Canvas API, Event Listeners)
- Google Fonts (Outfit)
